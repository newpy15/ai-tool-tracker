# ai-tool-tracker

### 무엇이 쓰이는지 보고, 토큰이 얼마나 드는지 보고, 안 쓰는 건 끄세요.

## 만든 이유

AI 코딩을 처음 시작하면 막막한 것이 있었습니다.

1. **내 결과물에 어떤 도구가 어디에 쓰였는지** 알기 어렵습니다. "동영상은 리모션으로 만들었다"처럼 나중에 되짚어 보고 싶은데 기록이 없습니다.
2. 설치한 플러그인과 스킬은 부르지 않아도 설명이 매번 AI에게 올라가 토큰을 씁니다. **어떤 플러그인이 얼마나 드는지, 어떤 것을 한 번도 안 쓰는지** 알 수 없어서, 안 쓰는 것을 직접 끌 수 있었으면 했습니다.
3. 어떤 플러그인이 **있는지, 무슨 일에 쓰는지** 잘 모릅니다. "동영상 만들어줘"라고 말할 때, 써 볼 만한 도구를 먼저 알려 주면 좋겠다고 생각했습니다.

그래서 "무엇이 쓰이고 얼마나 드는지 보여주고, 안 쓰는 것은 끄게 해 주고, 필요한 도구를 찾아 주는" 패널을 만들었습니다. 초보자도 쉽게 플러그인을 찾아보고, 오류와 개선점을 같이 나눌 수 있도록 GitHub에 공개합니다. 이 플러그인은 Claude Code와 대화하면서 만들었고, 실제 PC에서 확인하며 고쳤습니다.

## 무엇을 하나요

**중심이 되는 두 가지**

1. **무엇이 쓰이는지 봅니다.** 작업하면서 쓰인 플러그인, 스킬, MCP 도구, 하위 에이전트를 한 줄 설명과 함께 실시간 로그로 보여주고, 켜 두었지만 7·14·30일 동안 안 쓴 플러그인을 **안 쓴 플러그인**으로 모아 줍니다.
2. **토큰을 줄입니다.** 설치한 플러그인은 설명이 매 대화에 올라가 토큰을 씁니다. 패널이 플러그인마다 대략 몇 토큰인지("상시 약 N 토큰"), 5시간·7일 사용량이 얼마나 찼는지 보여 주고, 플러그인을 하나씩·묶음별로·한꺼번에 끄거나, 그 일에 맞는 것만 켜 두는 **작업 모드**를 고르게 해 줍니다.

**덤으로**: 만들고 싶은 것에 맞는 도구를 별 개수, 출처 등급, 소유자와 함께 추천하고, 플러그인을 용도(영상, 자막, 기획, 개발 …)별로 묶어 보여주고, **클로드 앱**에 설치한 플러그인은 Claude Code 것과 섞이지 않게 읽기 전용 `Claude 앱` 구역에 따로 보여줍니다. 화면은 한국어, 영어, 일본어, 중국어로 볼 수 있습니다.

**고급(기본은 꺼짐)**: *분업*은 묶음마다 전용 하위 에이전트를 두고 모델과 토큰 한도를 정하게 합니다. 매 턴 조금씩 늘어나는 부분이 있어서 기본 흐름에는 넣지 않았습니다.

## 신경 쓴 부분

- **초보자 눈높이**: 네 가지 언어(한국어, 영어, 일본어, 중국어), 화면 문구를 모두 직접 적음, 도구마다 한 줄 설명, 용어 풀이.
- **추천 링크를 믿어도 되는지**: 출처 등급과 소유자를 항목마다 보여주고, 남이 쓴 이름·주소·설명을 그대로 믿지 않습니다. (아래 "추천 링크를 믿어도 되나요?")
- **투명함**: 무엇을 읽고, 무엇을 인터넷으로 보내고, 무엇을 바꾸는지 모두 적어 두었습니다. 자동으로 보내거나 자동으로 설치하는 것은 없습니다.
- **토큰**: 파일을 훑는 일에는 모델을 쓰지 않습니다. 모델은 번역과, 영어가 아닌 검색어를 영어로 바꾸는 데에만 쓰고(가장 낮은 등급), 번역은 저장해서 다시 하지 않습니다.
- **조심스러운 동작**: 지우기와 옮기기는 확인을 거칩니다. 이 플러그인 자신은 끌 수 없게 막아 두었습니다. 지우기 직전에 한 번 더 확인합니다.
- **PC마다 다른 환경**: 설정 폴더가 다른 곳(`CLAUDE_CONFIG_DIR`, 다른 드라이브)에 있어도 찾습니다. **환경** 탭에서 무엇을 읽었는지 확인할 수 있습니다.
- **시험**: 안전·순위·분류 규칙은 시험 파일로 따로 시험하고(지금 90개), 안전 규칙은 실제 디렉터리 3,700여 개 전체에 적용해 확인했습니다.

## 빠른 시작

터미널의 Claude Code에서 설치합니다.

```
/plugin install ai-tool-tracker --marketplace newpy15/ai-tool-tracker
```

셸(명령 프롬프트, PowerShell 등)에서는:

```
claude plugin install ai-tool-tracker --marketplace newpy15/ai-tool-tracker
```

데스크톱 앱에서는 `/plugin`이 동작하지 않으므로: 입력창 옆 **+** → **Plugins** → **Add marketplace**에 `newpy15/ai-tool-tracker` 입력 → **Add plugin**.

- 설치 중 "Add marketplace?" 질문에는 `y`, 범위는 보통 첫 번째(user)를 고르면 됩니다.
- 설치 직후 "설정 항목 2개가 아직 없음(언어, 최소 별 개수)"이라는 안내가 나올 수 있습니다. 기본값(한국어, 별 10개)으로 동작하니 그대로 두셔도 되고, 둘 다 나중에 패널의 **환경** 탭에서 바꿀 수 있습니다.
- 설치하면 바로 활성화됩니다. 패널이 보이지 않으면 입력창에 `/ai-tools`를 입력하세요. 그래도 안 보이면 Claude Code를 완전히 껐다가 다시 켜 보세요.

### 만들고 싶은 것을 말해 보세요

```text
동영상과 pdf를 만들어줘.
```

패널이 주제(동영상, 문서)를 알아보고, 맞는 도구를 **추천** 탭에 보여줍니다. 문장은 만들고 싶은 것으로 바꿔 쓰세요.

### 명령어

| 입력 | 하는 일 |
| --- | --- |
| `/ai-tools` | 패널을 열고 설치된 도구 목록을 다시 읽습니다. 플러그인을 새로 깔거나 지운 뒤에 한 번 입력하세요. |
| `/ai-find 동영상 제작` | 원하는 기능으로 도구를 찾습니다. 이 PC의 디렉터리와 GitHub를 함께 찾고, 별 개수도 알아서 확인한 뒤 결과를 **추천** 탭에 보여줍니다. 주제가 여러 개(`동영상 pdf`)면 주제마다 따로 보여줍니다. |
| `/ai-log 이미지생성도구 로고 시안` | Claude Code 밖에서 쓴 도구를 직접 기록합니다. (밖에서 쓴 것은 자동으로 알 수 없습니다.) |

- 일반 대화 중에 "동영상 만들어줘", "pdf 만들어줘"처럼 주제가 담긴 말을 하면 알림이 뜨고 **추천** 탭에 결과가 쌓입니다. 이때는 이 PC의 디렉터리만 읽습니다. 같은 주제는 10분에 한 번만 알리고, 이미 설치한 것뿐이면 알리지 않습니다.
- **추천 결과는 설치를 대신 해 주지 않습니다.** 설치 명령을 복사해 드릴 뿐입니다. 항목마다 출처 등급과 소유자가 붙으니, 아래 "추천 링크를 믿어도 되나요?"를 읽고 설치 전에 코드와 권한을 직접 확인하세요.

### 처음 5분 따라 하기

1. **설치**: 위 방법으로 설치합니다.
2. **패널 열기**: 시작하면 패널이 자동으로 열립니다. 안 보이면 `/ai-tools`를 입력합니다.
3. **도구 탭 보기**: `플러그인`과 `스킬` 버튼으로 구역을 바꿔 가며, 내 PC에 뭐가 깔려 있고 각각 무슨 일을 하는지 읽어 봅니다. 이름을 누르면 안에 든 것이 펼쳐집니다.
4. **평소처럼 작업하기**: 작업하다가 **실시간 로그** 탭을 보면, 방금 쓰인 도구가 종류별로 쌓여 있습니다.
5. **토큰 줄이기**: **도구** 탭에서 플러그인마다 "상시 약 N 토큰"과 **안 쓴 플러그인**을 보고, 필요 없는 것을 끕니다. 안 쓴 목록은 이 플러그인이 7·14·30일 동안 작업을 지켜본 뒤에 채워집니다.
6. **도구 찾기**: 만들고 싶은 것을 말하거나(`동영상 만들어줘`), `/ai-find 동영상 제작`을 입력한 뒤 **추천** 탭을 봅니다.

### 이럴 땐 이렇게

| 하고 싶은 일 | 방법 |
| --- | --- |
| 방금 어떤 도구가 쓰였는지 보고 싶다 | **실시간 로그** 탭 |
| 이 플러그인이 뭘 하는 건지 모르겠다 | **도구** 탭에서 이름을 눌러 펼치기 |
| 클로드 앱(Claude Code가 아님)에 설치한 플러그인을 보고 싶다 | **도구** 탭 → `플러그인`, `스킬` 옆의 `Claude 앱` 버튼(읽기 전용, 앱이 관리) |
| 플러그인을 켜 두기만 해도 대략 몇 토큰이 드는지 보고 싶다 | **도구** 탭: 플러그인마다 "상시 약 N 토큰"과 맨 위 합계(어림값이며, 끄면 줄어듭니다) |
| 깔아만 두고 안 쓰는 플러그인을 찾아 끄고 싶다 | **도구** 탭 → **안 쓴 플러그인**: 켜 둔 플러그인 중 7·14·30일 동안 안 쓰인 것을 상시 토큰과 `끄기` 버튼과 함께 보여줍니다(그만큼 기록을 모은 뒤부터) |
| 안 쓰는 플러그인을 꺼서 토큰을 줄이고 싶다 | **도구** 탭 → 플러그인 줄의 `끄기` 버튼 (아래 "주의사항" 참고) |
| 플러그인을 한꺼번에 끄거나 켜고 싶다 | **도구** 탭 → `전체 끄기` / `전체 켜기`, 또는 "동영상" 같은 묶음의 `이 묶음 끄기` (먼저 물어봅니다) |
| 지금 하려는 일(영상, 문서, 웹·개발, 데이터)에 맞는 것만 켜고 싶다 | **작업 모드** 탭(무엇이 바뀌는지 보여 주고 먼저 묻습니다). 지금 켜진 것으로 내 프리셋을 만들고, 어떤 플러그인을 둘지 편집하고, 이름을 바꾸거나 지울 수 있습니다(최대 6개) |
| 큰 작업 전에 사용량 한도가 얼마나 남았는지 보고 싶다 | 탭 아래 **사용량** 줄(5시간·7일 막대와 초기화까지 남은 시간). 80%를 넘으면 안내가 나옵니다 |
| 만들고 싶은 것에 쓸 도구를 찾고 싶다 | 그 말을 하거나 `/ai-find 원하는 기능` → **추천** 탭 |
| 화면 언어를 바꾸고 싶다 | **환경** 탭 맨 위 언어 버튼 |
| 플러그인을 새로 깔거나 지웠는데 목록이 그대로다 | `/ai-tools` |
| Claude Code 밖에서 쓴 도구를 기록하고 싶다 | `/ai-log 도구이름 한 일` |
| (고급) 묶음마다 전용 하위 에이전트에게 일을 맡기고 모델·토큰 한도를 정하고 싶다 | **환경** 탭 → "분업" → `켜기`, 그다음 묶음마다 모델(Haiku, Sonnet, Opus 5.5, Fable 5.2 등 또는 모델 ID 직접 입력)을 고르고 `150k` 같은 토큰 한도를 직접 입력 |

## 어떻게 돌아가나요

ai-tool-tracker는 훅(hook) 모듈 하나로 이루어진 Claude Code 플러그인입니다. Claude Code가 하는 일을 **지켜보고**, 짧은 기록을 남기고, 패널을 **그립니다**. Claude가 하는 일은 바꾸지 않습니다. 훅은 호출과 입력을 언제나 그대로 통과시키고, 이 플러그인이 고장 나도 Claude Code는 이 플러그인이 없는 것처럼 계속 동작합니다.

```text
  Claude Code
  ┌────────────────────────────────────────────────────────────┐
  │  요청을 입력 ───────────► prompt.submit ─┐                 │
  │  Claude가 도구를 씀 ────► tool.call ─────┼──► 패널 상태    │
  │  /ai-tools … 입력 ──────► command.run ───┘        │        │
  └───────────────────────────────────────────────────┼────────┘
                                                      ▼
   읽기만 함                                   ┌─────────────┐
   ~/.claude: 설치된 플러그인, 스킬,      ───► │  ui.render  │ ───► 패널 (탭 5개)
   설정, 플러그인 디렉터리 캐시                └─────────────┘
                                                      ▲
   버튼을 누르거나 /ai-find를 입력했을 때만           │
   검색어 한 단어 ───► api.github.com ───► 신뢰 검사 ──► 추천
```

### 구성 요소

| 구성 요소 | 파일 | 하는 일 |
| --- | --- | --- |
| 훅 모듈 | `hooks/register.tsx` | 아래 훅을 등록하고, 설치된 도구를 읽고, 패널을 그리고, 버튼을 실행합니다. |
| 신뢰 규칙 | `hooks/trust.ts` | 남이 쓴 글을 정리하고, 안전한 이름·명령·링크를 만들고, 출처 등급을 정하고, 주의 신호를 붙이는 순수 함수 모음입니다. 시험에 Claude Code가 필요 없습니다. 추천을 관련도와 별 개수로 순위 매기는 것도 여기 있습니다. |
| 분업 | `hooks/agents.ts` | 용도별 하위 에이전트를 위한 순수 함수 모음입니다: 설정 검사, 안전한 에이전트 정의(검증된 플러그인 이름만 넣고 남이 쓴 글은 넣지 않음), 토큰 세기, 한도 규칙. |

### 정보는 어디서 오나요

- **설치된 도구**: Claude 설정 폴더에 있는 플러그인 자체의 파일(`installed_plugins.json`, 각 `SKILL.md` 머리말, `plugin.json`, 에이전트와 MCP 파일)과, 무엇이 켜져 있는지 알려 주는 `settings.json`입니다. 추측하지 않습니다.
- **설명**: 각 도구가 스스로 적어 둔 설명을 씁니다. 널리 쓰이는 열두 가지 도구(Remotion, Figma, Notion 등)는 기록에 직접 적은 짧은 설명도 함께 보여줍니다.
- **추천**: 이 PC에 받아 둔 플러그인 디렉터리 파일과 내가 추가한 마켓플레이스, 그리고 요청했을 때의 GitHub 검색입니다.
- **번역**: 한국어와 영어 화면은 직접 적은 것입니다. 다른 언어는 모델(가장 낮은 등급)이 한 번 번역하고, 검사(알맞은 글자인지, 자리표시가 남아 있는지)한 뒤 영어 원문과 함께 저장합니다. 그래서 문장이 바뀌면 다시 번역하고, 바뀌지 않았으면 다시 하지 않습니다.

### 추천 하나가 만들어지는 과정

1. 사전에서 주제를 알아봅니다(예: "동영상", "pdf", "슬라이드").
2. 이 PC의 디렉터리와 내가 추가한 마켓플레이스를 검색합니다. 결과마다 관련도 점수를 매깁니다: 검색어가 이름에 있으면 3점, 설명 앞부분에 있으면 2점, 설명 뒤쪽에서만 언급되면 1점입니다.
3. `별 개수 확인` 버튼을 누르거나 `/ai-find`를 입력하면(이 경우 알아서 합니다) GitHub에서 별 개수를 가져옵니다. 한 번에 저장소 6개까지 묻고, 공개된 저장소 이름(`owner/repo`)만 보냅니다.
4. 버튼을 누르거나 `/ai-find`를 입력했을 때만 GitHub를 주제별(`claude-code-plugin`, `claude-skills`, `claude-code`)로, 가장 잘 맞는 순으로 검색하고, 검색어가 나오지 않는 결과는 버립니다. 검색어 한 단어만 보냅니다.
5. 디렉터리와 GitHub 결과를 저장소별로 합칩니다. **별이 가장 많은 2개**를 "추천"으로 먼저 보여줍니다. 이름이나 저장소 주제로 그 일을 한다고 밝힌 것(관련도 3)이 먼저이고, 그다음 설명 앞부분에 언급한 것(관련도 2)입니다. 검토되지 않은 저장소가 최소 별 개수(기본 10개)보다 적으면 추천에서 빠지고 경고가 붙습니다. 나머지는 `나머지 N개 보기` 뒤에 접혀 있습니다.
6. 모든 결과가 아래의 신뢰 검사를 거칩니다. 출처 등급, 소유자, 주의 신호를 정하고, 링크와 설치 명령은 검증된 부분으로 다시 만듭니다. 아무것도 설치하지 않습니다.

### 무엇을 어디에 보관하나요

- **기록과 패널의 상태**(어느 탭을 보는지, 마지막 추천)는 이 플러그인을 위한 Claude Code의 세션 상태에 있습니다. 어디로도 보내지 않습니다.
- **번역**은 다시 하지 않도록 세션이 바뀌어도 저장해 둡니다.
- **작업 모드는 플러그인을 실제로 켜고 끕니다.** 먼저 묻고, "기타" 묶음과 이 플러그인 자신은 건드리지 않으며, 다음에 Claude Code를 시작할 때부터 반영됩니다. 내 프리셋에는 이름과 켜 둘 플러그인 이름만 저장하며, 고치고 이름을 바꾸고 지울 수 있습니다.
- **작은 사용 기록**(플러그인 이름, 마지막으로 쓰인 시각, 횟수만)을 세션이 바뀌어도 남겨서 어떤 플러그인이 안 쓰였는지 알려 줍니다. 어디로도 보내지 않으며, 이 플러그인이 호출되는 것을 볼 수 있는 도구만 기록합니다. 도구를 부르지 않고 돕는 플러그인(테마 등)은 안 쓴 것처럼 보일 수 있습니다.
- **내 파일은 내가 누른 버튼으로만 바뀝니다.** 플러그인 켜기/끄기와 설치는 `claude` 명령을 씁니다. "전체로 옮기기"는 폴더 전용 스킬을 `~/.claude/skills`로(세션 전용 모드는 `~/.claude/local-mods`로) 복사하고, "옛 캐시 지우기"와 "원본 삭제"는 각각 확인을 거친 뒤 폴더를 지웁니다.

## 추천 링크를 믿어도 되나요?

추천 목록의 이름, 설명, 주소는 모두 **남이 쓴 글**입니다. 그래서 이 플러그인은 믿을 만한 정도를 항목마다 보여주고, 남이 쓴 글을 그대로 믿지 않도록 만들었습니다. **다만 이 표시는 참고용이며 안전을 보장하지 않습니다.**

**출처 등급 (항목마다 표시)**

| 표시 | 뜻 |
| --- | --- |
| 공식 마켓플레이스 | Claude 공식 마켓플레이스(`claude-plugins-official`)에 든 것 |
| Anthropic 검토 / 파트너 검토 | 플러그인 디렉터리 기록에 그 쪽의 검토가 끝났다고 적힌 것 |
| 내가 추가한 마켓플레이스 | 내가 직접 추가한 마켓플레이스에 든 것 |
| 디렉터리 등록 · 검토 전 | 디렉터리에 올라 있지만 검토 기록이 없는 것 (이 PC의 디렉터리 기준 3,700여 개 중 대부분) |
| 출처 미확인 (GitHub 검색) | GitHub 검색에서 나온 것. 디렉터리에도 있으면 그 등급을 따릅니다 |

- **소유자(GitHub 계정)를 항상 같이 보여줍니다.** 이름만 비슷한 도구가 실제로 있습니다. 예를 들어 `Figma`의 소유자는 공식 `figma`지만 "figma-suite" 같은 이름은 다른 개인 계정의 것입니다. 소유자가 맞는지 먼저 보세요.
- **GitHub 결과에는 주의 신호가 붙습니다.** 1년 넘게 갱신이 없음, 만든 지 30일이 안 됨, 라이선스 없음, 다른 저장소의 복제본, 별 수에 비해 복제한 사람이 아주 적음(별 수는 조작될 수 있습니다). 추천은 주제와 얼마나 맞는지, 그다음 별 수 순으로 정합니다("추천 하나가 만들어지는 과정" 참고). 출처 등급과 주의 신호는 줄마다 표시됩니다.

**남이 쓴 글을 그대로 믿지 않습니다**

- 링크는 목록에 적힌 주소를 쓰지 않고, 검증한 `owner/repo`로 `https://github.com/…` 주소를 직접 만듭니다. `github.com`이 아닌 주소는 링크로 만들지 않습니다.
- 설치 명령은 이름이 영문자, 숫자, `.`, `_`, `-`로만 이루어졌을 때만 만듭니다. 실제 디렉터리에는 `S&P Global`처럼 명령에 그대로 쓰면 위험한 특수문자가 든 이름이 66개 있습니다. 그런 것은 저장소 주소 기반 명령으로 바꾸고, 그것도 안전하지 않으면 명령을 만들지 않습니다.
- 화면에 찍기 전에 줄바꿈, 제어 문자, 글자 방향을 뒤집는 문자 같은 눈속임 글자를 없앱니다.
- 설치는 대신 해 주지 않습니다. 명령을 복사해 드리고, 어떤 명령인지 화면에 그대로 보여줍니다.

이 규칙은 `hooks/trust.ts`에 있고, Claude Code 없이 단독으로 시험할 수 있습니다: `node --test test/` (Node 23.6 이상). 허점을 발견하면 Issues로 알려 주세요.

## 토큰은 얼마나 드나요?

- **이 플러그인 자체는 대화(모델이 읽는 내용)에 아무것도 더하지 않습니다.** 패널 화면과 기록은 모델에게 가지 않습니다.
- 모델을 부르는 곳은 두 가지뿐입니다. 설명을 선택한 언어로 번역할 때(영어 설명을 한국어로 보여줄 때 포함), 그리고 `/ai-find`의 영어로 쓰지 않은 검색어(한국어, 일본어, 중국어 등)를 영어 검색어로 바꿀 때입니다. 둘 다 가장 낮은 등급(haiku)을 쓰고, 번역은 저장해서 다시 하지 않습니다. 파일을 훑는 일에는 모델을 쓰지 않습니다.
- **설치한 다른 플러그인은 따로 토큰을 씁니다.** 스킬과 서브에이전트의 이름과 한 줄 설명이 매 턴 AI에게 올라갑니다. 글자 수로 어림해 본 값(실제 토큰 수가 아닙니다)으로, 필자의 PC에서 플러그인 9개와 스킬 15개의 설명은 매 턴 약 6,600토큰이었고, 큰 것 3개를 끄면 약 3,700토큰이 줄어드는 정도였습니다. 안 쓰는 것을 끄는 것이 가장 확실한 절약입니다.

## 주의사항

- **켜기/끄기는 확인 창 없이 바로 적용됩니다.** 끄는 것은 파일을 지우는 것이 아니라 설정을 바꾸는 것이라 언제든 다시 켤 수 있습니다. 실제로 반영되는 것은 **다음에 Claude Code를 시작할 때**부터입니다.
- **옛 캐시 지우기는 되돌릴 수 없습니다.** 현재 설치된 버전과 사용 중 표시가 있는 폴더는 건드리지 않고, 지우기 전에 확인을 묻습니다.
- **"전체로 옮기기"는 복사입니다.** 원본은 그대로 두고, 원본 삭제는 별도로 한 번 더 확인합니다. 복사한 뒤 원본을 고쳐도 자동으로 반영되지 않습니다.
- **추천은 안전을 보장하지 않습니다.** 설치 전에 소유자가 맞는지, 저장소의 코드와 요구하는 권한을 직접 확인하세요.
- **끄기를 잘못 누르지 마세요.** 쓰고 있는 플러그인을 끄면 다음 시작부터 그 기능이 사라집니다. 다시 `켜기`를 누르면 됩니다.
- **분업은 사용량 한도를 지켜 줍니다.** 5시간 기준과 주간(7일) 기준을 따로 고를 수 있고(각각 기본 80%, 10~100%를 10% 단위로 선택, 하나는 "쓰지 않음"도 가능하지만 둘 다는 안 됨), 고른 사용량이 그 기준 이상이면 새 하위 에이전트를 시작하지 않고, 한 번의 요청에서는 최대 4개까지만 시작합니다. "영상 만들어줘" 한 번에 여러 개가 한꺼번에 뜨지 않게 하려는 것입니다. 그래도 이미 도는 하나를 중간에 끊지는 못하므로 한도와 최대 턴을 낮게 두세요. 위험을 낮추는 장치이지 없애는 장치는 아닙니다.
- **"상시 약 N 토큰"은 플러그인이 쓴 양이 아닙니다.** 쓰지 않아도 매 대화에 올라가는 설명을 Claude Code가 어림한 값입니다. 작업 중 플러그인이 실제로 쓴 양은 모두 한 대화에 섞여서 따로 나눌 수 없습니다.
- **사용량 막대는 Claude Code가 알려 주는 퍼센트입니다.** 5시간 한도의 정확한 토큰 수는 공개되지 않아서 이 플러그인도 토큰 숫자를 보여주지 않습니다. 60%를 넘으면 가벼운 일은 Haiku에 맡기라고 권하고, 80%와 95%를 넘는 순간 한 번 알립니다. 값을 읽기만 하며, 비용이 들지 않고 어디로도 보내지 않습니다.
- **Claude 앱 플러그인은 따로 보여주고, 여기서는 켜고 끌 수 없습니다.** 클로드 앱(대화, Cowork)은 Claude Code와 별개의 저장소에 플러그인을 설치합니다. 도구 탭의 `플러그인`, `스킬` 옆에 `Claude 앱` 구역을 따로 두고 "앱" 표시와 마켓플레이스, 소유자를 붙여서, Claude Code가 불러오는 마켓플레이스·GitHub 플러그인과 섞이지 않게 했습니다. Claude Code 세션에서 쓰이는지는 확인되지 않아서 토큰 어림값은 붙이지 않았습니다.
- **분업은 기본이 꺼져 있습니다.** 켜면 모델이 매 턴 읽는 에이전트 목록에 묶음마다 한 줄이 늘어납니다(토큰이 조금 듭니다). 모델마다 토큰 한도와 최대 턴의 기본값·최소·최대가 따로 있고(하위 에이전트는 시작만 해도 약 6만 토큰이 들어서 한도는 최소 10만이며, 비싼 모델일수록 최대가 낮고, "제한 없음"은 받지 않습니다) 한 번 실행에 한도가 바닥나지 않게 했습니다. 토큰 한도는 새 하위 에이전트를 시작할 때 확인하고, 이미 도는 것을 중간에 끊지는 않으며 길이는 "최대 턴"으로 막습니다. 사용량은 이번 세션 것만, 이 플러그인이 만든 하위 에이전트만 셉니다.
- **`전체 끄기`와 `이 묶음 끄기`는 먼저 확인을 받습니다.** 이 플러그인 자신은 절대 끄지 않고, 다음에 Claude Code를 시작할 때부터 반영됩니다. 다시 켜는 것도 같습니다.
- **별 개수는 인기이지 품질이 아닙니다.** 별은 부풀려질 수 있고, 인기 있는 도구가 나에게는 맞지 않을 수도 있습니다. 설명을 읽고 소유자를 확인하세요. 별이 적다고 나쁜 것은 아니고, 근거가 적을 뿐입니다.
- 켜기/끄기, 옮기기, 설치 관련 기능은 `claude` 명령을 사용합니다. 이 명령이 없는 환경(예: 데스크톱 앱만 쓰는 경우)에서는 실패할 수 있습니다. 환경 탭의 "감지한 환경"에 사용 가능 여부가 표시됩니다.
- 이 플러그인은 Claude Code의 플러그인 기능 중 아직 초기 단계인 부분을 씁니다. Claude Code가 업데이트되면 동작이 바뀔 수 있습니다.

## 내 컴퓨터에서 무엇을 하나요? (투명하게 적습니다)

**읽는 것**: Claude 설정 폴더(`~/.claude`, 또는 `CLAUDE_CONFIG_DIR`로 지정한 곳)의 설치 기록, 스킬 파일, 설정, 플러그인 디렉터리 캐시, 알려진 프로젝트 목록. 윈도우에서는 클로드 앱이 자기 폴더(`%LOCALAPPDATA%\Claude-Data\...\rpm`)에 둔 플러그인 목록(목록 파일, 플러그인마다 `plugin.json`, 스킬 설명, MCP 연결 유무)도 읽기만 합니다. 다른 운영체제는 저장 위치가 달라서 확인하지 못했습니다.

**인터넷으로 나가는 것**
- GitHub: **추천 탭의 버튼을 누르거나 `/ai-find`를 입력했을 때만**, `video` 같은 검색어 한 단어와, 별 개수 확인을 위해 추천하려는 저장소의 공개 이름(`owner/repo`)이 `api.github.com`으로 나갑니다. 대화 내용이나 로그인 정보는 보내지 않습니다.
- 모델 호출: 위 "토큰은 얼마나 드나요?"에 적은 두 경우뿐입니다.
- 말한 내용의 원문은 저장하지도, 전송하지도 않습니다. 감지한 주제와 검색어만 씁니다.

**바꾸는 것 (버튼을 눌렀을 때만)**
- 플러그인 켜기/끄기: `claude plugin enable|disable`을 실행합니다.
- 폴더 전용 도구를 전체로 옮기기: 확인 후 복사합니다. 원본 삭제는 따로 한 번 더 확인합니다.
- 옛 캐시 지우기: 확인 후 지웁니다.
- 이 플러그인 자신은 끌 수 없게 막아 두었습니다.

## 알려진 한계

- **윈도우의 Claude Code 데스크톱 앱에서만 확인했습니다.** 맥, 리눅스, 터미널, VS Code에서는 확인하지 못했습니다. 코드에 맥·리눅스용 분기는 있지만 실행해 본 적이 없습니다.
- Claude Code 전용입니다. Claude Code 밖에서 쓴 도구는 자동으로 알 수 없어서, 필요하면 `/ai-log`로 직접 기록해야 합니다.
- **추천은 이 PC에 받아 둔 플러그인 디렉터리 파일(`plugin-directory-cache-v2.json`)에 의존합니다.** 파일이 없거나 이름이 바뀌면 추가한 마켓플레이스 목록으로만 찾습니다. GitHub 검색은 그와 상관없이 동작합니다.
- 추천은 단어 사전으로 주제를 알아봅니다. 사전에 없는 주제는 놓칠 수 있고(그럴 땐 `/ai-find 원하는 기능`), 별 개수가 많다고 좋은 도구는 아닙니다.
- **출처 등급과 주의 신호는 디렉터리 기록과 GitHub 응답에 든 값만으로 정한 것입니다.** 저장소의 코드를 직접 읽어 안전한지 검사하지는 않습니다. 소유자 이름이 맞아도 코드가 안전하다는 뜻은 아닙니다.
- GitHub 검색은 로그인 없이 쓰므로 1분에 10번까지입니다. `/ai-find`는 주제마다 최대 5번(별 확인 2번, 주제 검색 3번) 쓰므로, 주제 세 개를 한꺼번에 찾으면 1분쯤 기다려야 할 수 있습니다.
- 주제는 단어 사전으로 알아보고, 관련도는 이름·설명·저장소 주제에 든 단어로 판단합니다. 일은 하지만 다른 말로 설명한 저장소는 순위가 낮을 수 있습니다.
- 번역 품질은 모델에 따라 다릅니다. 어색한 번역을 발견하면 알려 주세요.

## 문제가 생겼을 때

| 증상 | 해 볼 것 |
| --- | --- |
| 패널이 안 보인다 | `/ai-tools`를 입력합니다. 그래도 안 되면 Claude Code를 완전히 껐다가 다시 켭니다. |
| 패널에 "Nothing to show yet"이라고만 나온다 | 패널을 그리다 오류가 났다는 뜻입니다. `/ai-tools`를 다시 입력해 보고, 계속되면 Issues에 대화창에 뜬 오류 줄(`ai-tool-tracker: … hook skipped`)을 붙여 주세요. |
| 설명이 영어로 보인다 | 번역이 끝나는 중일 수 있습니다. 몇 분 뒤에도 그대로면 환경 탭의 "번역 상태"를 확인하고 알려 주세요. |
| 추천이 안 나온다 | 사전에 없는 주제일 수 있습니다. `/ai-find 원하는 기능`으로 직접 찾아 보세요. |
| GitHub 검색이 "rate limit"으로 실패한다 | 로그인 없이 쓰는 검색은 1분에 10번까지입니다. 1분 뒤에 다시 시도하세요. |
| 켜기/끄기, 옮기기가 실패한다 | 환경 탭의 "감지한 환경"에서 `claude` 명령이 있는지 확인하세요. |
| 맥·리눅스에서 이상하다 | 아직 확인하지 못한 환경입니다. Issues에 환경 정보와 함께 알려 주세요. |

## 용어를 모르신다면

- **플러그인**: Claude Code에 기능을 덧붙이는 묶음입니다. 스킬, 에이전트, MCP 서버, 훅을 담을 수 있습니다.
- **스킬**: 특정 작업의 방법을 적어 둔 지침서입니다. 부르거나 Claude가 필요하다고 판단할 때만 읽어서 따릅니다. 안 쓰는 동안은 이름과 한 줄 설명만 올라가 있습니다.
- **MCP 서버**: 외부 서비스(Notion, Figma 등)와 연결해 주는 도구입니다.
- **훅**: 어떤 일이 일어날 때 자동으로 실행되는 코드입니다. 켜져 있는 동안 계속 동작하므로, 끄면 효과가 가장 큽니다.

## 면책

독립적인 프로젝트이며, Anthropic과 관련이 없고 보증을 받은 것도 아닙니다. 추천은 편의를 위한 것이지 권유나 보증이 아니며, 설치하는 것에 대한 책임은 만든 사람이 지지 않습니다. 소프트웨어는 있는 그대로 제공되며 MIT 라이선스를 따릅니다.

## 기여하기

오류 제보, 아이디어, 작고 목적이 분명한 풀 리퀘스트를 환영합니다. 풀 리퀘스트를 열기 전에 아래 검사를 돌려 주세요.

```
node --test test/
claude plugin validate .
```

- **오류와 아이디어**: [Issues](https://github.com/newpy15/ai-tool-tracker/issues)에 남겨 주세요. 양식을 준비해 두었습니다. 오류는 패널 **환경** 탭의 "감지한 환경" 내용을 붙여 주시면 원인을 찾기 쉽습니다(사용자 이름이 든 경로는 가려 주세요). 아이디어는 "이런 말을 했을 때 이런 도구가 추천되면 좋겠다"처럼 예시가 있으면 더 좋습니다.
- **보안**: 이 플러그인이 안전하지 않은 링크나 명령을 만들게 하는 방법을 발견하시면, 공격 방법의 자세한 내용은 빼고 제목이 `[Security]`인 Issue를 열어 주세요. 제가 이어서 연락드리겠습니다.
- **규칙**: 남이 쓴 글을 다루는 코드는 `hooks/trust.ts`에 두고, `test/trust.test.mjs`에 시험을 함께 넣습니다.
