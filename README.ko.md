# ai-tool-tracker

**English README: [README.md](README.md)**

**Claude Code 옆에 붙는 패널입니다. 작업하면서 어떤 플러그인·스킬을 썼는지 실시간으로 보여주고, "동영상 만들어줘" 같은 요청에 쓸 만한 도구를 찾아 추천합니다. 쓰지 않는 플러그인은 버튼으로 끌 수 있습니다.**

## 만든 이유

AI 코딩을 처음 시작하면 막막한 것이 있었습니다.

1. **내 결과물에 어떤 도구가 어디에 쓰였는지** 알기 어렵습니다. "동영상은 리모션으로 만들었다"처럼 나중에 되짚어 보고 싶은데 기록이 없습니다.
2. 어떤 플러그인이 **있는지, 무슨 일에 쓰는지** 잘 모릅니다. "동영상 만들어줘"라고 말할 때, 써 볼 만한 도구를 먼저 알려 주면 좋겠다고 생각했습니다.
3. 설치한 플러그인과 스킬은 부르지 않아도 설명이 매번 AI에게 올라가 토큰을 씁니다. 안 쓰는 것은 직접 끌 수 있었으면 했습니다.

그래서 "쓴 도구를 보여주고, 필요한 도구를 찾아 주고, 안 쓰는 것은 끄게 해 주는" 패널을 만들었습니다. 초보자도 쉽게 플러그인을 찾아보고, 오류와 개선점을 같이 나눌 수 있도록 GitHub에 공개합니다. 이 플러그인은 Claude Code와 대화하면서 만들었고, 실제 PC에서 확인하며 고쳤습니다.

## 신경 쓴 부분

- **초보자 눈높이**: 한국어 화면, 도구마다 한 줄 설명, 용어 풀이. 한국어·영어 외에 일본어, 중국어, 스페인어, 프랑스어, 독일어도 고를 수 있습니다.
- **추천 링크를 믿어도 되는지**: 출처 등급과 소유자를 항목마다 보여주고, 남이 쓴 이름·주소·설명을 그대로 믿지 않습니다. (아래 "추천 링크를 믿어도 되나요?")
- **투명함**: 무엇을 읽고, 무엇을 인터넷으로 보내고, 무엇을 바꾸는지 모두 적어 두었습니다. 자동으로 보내거나 자동으로 설치하는 것은 없습니다.
- **토큰**: 파일을 훑는 일에는 모델을 쓰지 않습니다. 모델은 번역에만 쓰고(가장 낮은 등급), 번역은 저장해서 다시 하지 않습니다.
- **조심스러운 동작**: 지우기와 옮기기는 확인을 거칩니다. 이 플러그인 자신은 끌 수 없게 막아 두었습니다. 지우기 직전에 한 번 더 확인합니다.
- **PC마다 다른 환경**: 설정 폴더가 다른 곳(`CLAUDE_CONFIG_DIR`, 다른 드라이브)에 있어도 찾습니다. 환경 탭에서 무엇을 읽었는지 확인할 수 있습니다.
- **시험**: 안전 규칙은 시험 파일로 따로 시험하고(7개), 실제 디렉터리 3,700여 개 전체에 적용해 확인했습니다.

## 무엇을 해 주나요?

패널에 탭이 네 개 있습니다.

| 탭 | 하는 일 |
| --- | --- |
| **도구** | 내 PC에 설치된 **플러그인**과 **스킬**을 설명과 함께 보여줍니다. 플러그인은 켜기/끄기를 할 수 있고, 이름을 누르면 안에 든 스킬·에이전트·MCP 서버가 펼쳐집니다. 스킬은 `/이름`으로 부르는 방법도 보여줍니다. |
| **실시간 로그** | 작업 중 쓰인 도구(스킬, 플러그인, 파일 편집, 명령 실행, 서브에이전트 등)를 시간순으로 쌓고, 종류별로 묶어 "무엇에 쓰이는 도구인지" 한 줄 설명을 붙입니다. |
| **추천** | "동영상과 pdf 만들어줘"처럼 말하면 주제(동영상, 문서 등)를 알아보고 맞는 도구를 주제별로 보여줍니다. 이 PC에 받아 둔 플러그인 디렉터리에서 먼저 찾고, 버튼을 누르면 GitHub에서 실시간으로 더 찾습니다. |
| **환경** | 언어 선택, 내 PC에서 무엇을 읽었는지(감지한 환경), 번역 진행 상황, 옛 버전 캐시 지우기, 특정 폴더에서만 쓰는 도구를 전체로 옮기기. |

## 설치

터미널의 Claude Code에서:

```
/plugin install ai-tool-tracker --marketplace newpy15/ai-tool-tracker
```

셸(명령 프롬프트, PowerShell 등)에서:

```
claude plugin install ai-tool-tracker --marketplace newpy15/ai-tool-tracker
```

데스크톱 앱에서는 `/plugin`이 동작하지 않으므로: 입력창 옆 **+** → **Plugins** → **Add marketplace**에 `newpy15/ai-tool-tracker` 입력 → **Add plugin**.

- 설치 중 "Add marketplace?" 질문에는 `y`, 범위는 보통 첫 번째(user)를 고르면 됩니다.
- 설치 직후 "설정 항목 1개가 아직 없음(언어)"이라는 안내가 나올 수 있습니다. 기본값(한국어)으로 동작하니 그대로 두셔도 되고, 언어는 나중에 패널의 **환경** 탭에서 바꿀 수 있습니다.
- 설치하면 바로 활성화됩니다. 패널이 보이지 않으면 입력창에 `/ai-tools`를 입력하세요. 그래도 안 보이면 Claude Code를 완전히 껐다가 다시 켜 보세요.

## 처음 5분 따라 하기

1. **설치**: 위 방법으로 설치합니다.
2. **패널 열기**: 시작하면 패널이 자동으로 열립니다. 안 보이면 `/ai-tools`를 입력합니다.
3. **도구 탭 보기**: `플러그인`과 `스킬` 버튼으로 구역을 바꿔 가며, 내 PC에 뭐가 깔려 있고 각각 무슨 일을 하는지 읽어 봅니다. 이름을 누르면 안에 든 것이 펼쳐집니다.
4. **평소처럼 작업하기**: 작업하다가 **실시간 로그** 탭을 보면, 방금 쓰인 도구가 종류별로 쌓여 있습니다.
5. **도구 찾기**: 만들고 싶은 것을 말하거나(`동영상 만들어줘`), `/ai-find 동영상 제작`을 입력한 뒤 **추천** 탭을 봅니다.

## 이럴 땐 이렇게

| 하고 싶은 일 | 방법 |
| --- | --- |
| 방금 어떤 도구가 쓰였는지 보고 싶다 | **실시간 로그** 탭 |
| 이 플러그인이 뭘 하는 건지 모르겠다 | **도구** 탭에서 이름을 눌러 펼치기 |
| 안 쓰는 플러그인을 꺼서 토큰을 줄이고 싶다 | **도구** 탭 → 플러그인 줄의 `끄기` 버튼 (아래 "주의사항" 참고) |
| 만들고 싶은 것에 쓸 도구를 찾고 싶다 | 그 말을 하거나 `/ai-find 원하는 기능` → **추천** 탭 |
| 화면 언어를 바꾸고 싶다 | **환경** 탭 맨 위 언어 버튼 |
| 플러그인을 새로 깔거나 지웠는데 목록이 그대로다 | `/ai-tools` |
| Claude Code 밖에서 쓴 도구를 기록하고 싶다 | `/ai-log 도구이름 한 일` |

## 사용법

| 입력 | 하는 일 |
| --- | --- |
| `/ai-tools` | 패널을 열고 설치된 도구 목록을 다시 읽습니다. 플러그인을 새로 깔거나 지운 뒤에 한 번 입력하세요. |
| `/ai-find 동영상 제작` | 원하는 기능으로 도구를 찾습니다. 이 PC의 디렉터리와 GitHub를 함께 찾고, 결과는 **추천** 탭에 나옵니다. 주제가 여러 개(`동영상 pdf`)면 주제마다 따로 보여줍니다. |
| `/ai-log 이미지생성도구 로고 시안` | Claude Code 밖에서 쓴 도구를 직접 기록합니다. (밖에서 쓴 것은 자동으로 알 수 없습니다.) |

- 일반 대화 중에 "동영상 만들어줘", "pdf 만들어줘"처럼 주제가 담긴 말을 하면 알림이 뜨고 **추천** 탭에 결과가 쌓입니다. 이때는 이 PC의 디렉터리만 읽습니다. 같은 주제는 10분에 한 번만 알리고, 이미 설치한 것뿐이면 알리지 않습니다.
- **추천 결과는 설치를 대신 해 주지 않습니다.** 설치 명령을 복사해 드릴 뿐입니다. 항목마다 출처 등급과 소유자가 붙으니, 아래 "추천 링크를 믿어도 되나요?"를 읽고 설치 전에 코드와 권한을 직접 확인하세요.

## 추천 링크를 믿어도 되나요?

추천 목록의 이름, 설명, 주소는 모두 **남이 쓴 글**입니다. 그래서 이 플러그인은 믿을 만한 정도를 항목마다 보여주고, 남이 쓴 글을 그대로 믿지 않도록 만들었습니다. **다만 이 표시는 참고용이며 안전을 보장하지 않습니다.**

**출처 등급 (항목마다 표시)**

| 표시 | 뜻 |
| --- | --- |
| 공식 마켓플레이스 | Claude 공식 마켓플레이스(`claude-plugins-official`)에 든 것 |
| Anthropic 검토 / 파트너 검토 | 플러그인 디렉터리 기록에 그 쪽의 검토가 끝났다고 적힌 것 |
| 내가 추가한 마켓플레이스 | 내가 직접 추가한 마켓플레이스에 든 것 |
| 디렉터리 등록 · 검토 전 | 디렉터리에 올라 있지만 검토 기록이 없는 것 (이 PC의 디렉터리 기준 3,700여 개 중 대부분) |
| 출처 미확인 (GitHub 검색) | GitHub 검색에서 나온 것. 디렉터리에도 있으면 그 등급을 따릅니다 |

- **소유자(GitHub 계정)를 항상 같이 보여줍니다.** 이름만 비슷한 도구가 실제로 있습니다. 예를 들어 `Figma`의 소유자는 공식 `figma`지만 "figma-suite" 같은 이름은 다른 개인 계정의 것입니다. 소유자가 맞는지 먼저 보세요.
- **GitHub 결과에는 주의 신호가 붙습니다.** 1년 넘게 갱신이 없음, 만든 지 30일이 안 됨, 라이선스 없음, 다른 저장소의 복제본, 별 수에 비해 복제한 사람이 아주 적음(별 수는 조작될 수 있습니다). 정렬은 출처 등급, 주의 신호가 적은 순, 별 수 순입니다.

**남이 쓴 글을 그대로 믿지 않습니다**

- 링크는 목록에 적힌 주소를 쓰지 않고, 검증한 `owner/repo`로 `https://github.com/…` 주소를 직접 만듭니다. `github.com`이 아닌 주소는 링크로 만들지 않습니다.
- 설치 명령은 이름이 영문자, 숫자, `.`, `_`, `-`로만 이루어졌을 때만 만듭니다. 실제 디렉터리에는 `S&P Global`처럼 명령에 그대로 쓰면 위험한 특수문자가 든 이름이 66개 있습니다. 그런 것은 저장소 주소 기반 명령으로 바꾸고, 그것도 안전하지 않으면 명령을 만들지 않습니다.
- 화면에 찍기 전에 줄바꿈, 제어 문자, 글자 방향을 뒤집는 문자 같은 눈속임 글자를 없앱니다.
- 설치는 대신 해 주지 않습니다. 명령을 복사해 드리고, 어떤 명령인지 화면에 그대로 보여줍니다.

이 규칙은 `hooks/trust.ts`에 있고, Claude Code 없이 단독으로 시험할 수 있습니다: `node --test test/` (Node 23.6 이상). 허점을 발견하면 Issues로 알려 주세요.

## 토큰은 얼마나 드나요?

- **이 플러그인 자체는 대화(모델이 읽는 내용)에 아무것도 더하지 않습니다.** 패널 화면과 기록은 모델에게 가지 않습니다.
- 모델을 부르는 곳은 두 가지뿐입니다. 설명을 선택한 언어로 번역할 때(영어 설명을 한국어로 보여줄 때 포함), 그리고 사전에 없는 한국어 검색어를 영어 검색어로 바꿀 때입니다. 둘 다 가장 낮은 등급(haiku)을 쓰고, 번역은 저장해서 다시 하지 않습니다. 파일을 훑는 일에는 모델을 쓰지 않습니다.
- **설치한 다른 플러그인은 따로 토큰을 씁니다.** 스킬과 서브에이전트의 이름과 한 줄 설명이 매 턴 AI에게 올라갑니다. 글자 수로 어림해 본 값(실제 토큰 수가 아닙니다)으로, 필자의 PC에서 플러그인 9개와 스킬 15개의 설명은 매 턴 약 6,600토큰이었고, 큰 것 3개를 끄면 약 3,700토큰이 줄어드는 정도였습니다. 안 쓰는 것을 끄는 것이 가장 확실한 절약입니다.

## 주의사항

- **켜기/끄기는 확인 창 없이 바로 적용됩니다.** 끄는 것은 파일을 지우는 것이 아니라 설정을 바꾸는 것이라 언제든 다시 켤 수 있습니다. 실제로 반영되는 것은 **다음에 Claude Code를 시작할 때**부터입니다.
- **옛 캐시 지우기는 되돌릴 수 없습니다.** 현재 설치된 버전과 사용 중 표시가 있는 폴더는 건드리지 않고, 지우기 전에 확인을 묻습니다.
- **"전체로 옮기기"는 복사입니다.** 원본은 그대로 두고, 원본 삭제는 별도로 한 번 더 확인합니다. 복사한 뒤 원본을 고쳐도 자동으로 반영되지 않습니다.
- **추천은 안전을 보장하지 않습니다.** 설치 전에 소유자가 맞는지, 저장소의 코드와 요구하는 권한을 직접 확인하세요.
- **끄기를 잘못 누르지 마세요.** 쓰고 있는 플러그인을 끄면 다음 시작부터 그 기능이 사라집니다. 다시 `켜기`를 누르면 됩니다.
- 켜기/끄기, 옮기기, 설치 관련 기능은 `claude` 명령을 사용합니다. 이 명령이 없는 환경(예: 데스크톱 앱만 쓰는 경우)에서는 실패할 수 있습니다. 환경 탭의 "감지한 환경"에 사용 가능 여부가 표시됩니다.
- 이 플러그인은 Claude Code의 플러그인 기능 중 아직 초기 단계인 부분을 씁니다. Claude Code가 업데이트되면 동작이 바뀔 수 있습니다.

## 내 컴퓨터에서 무엇을 하나요? (투명하게 적습니다)

**읽는 것**: Claude 설정 폴더(`~/.claude`, 또는 `CLAUDE_CONFIG_DIR`로 지정한 곳)의 설치 기록, 스킬 파일, 설정, 플러그인 디렉터리 캐시, 알려진 프로젝트 목록.

**인터넷으로 나가는 것**
- GitHub 검색: **추천 탭의 버튼을 누르거나 `/ai-find`를 입력했을 때만**, `video` 같은 검색어 한 단어가 `api.github.com`으로 나갑니다. 대화 내용이나 로그인 정보는 보내지 않습니다.
- 모델 호출: 위 "토큰은 얼마나 드나요?"에 적은 두 경우뿐입니다.
- 말한 내용의 원문은 저장하지도, 전송하지도 않습니다. 감지한 주제와 검색어만 씁니다.

**바꾸는 것 (버튼을 눌렀을 때만)**
- 플러그인 켜기/끄기: `claude plugin enable|disable`을 실행합니다.
- 폴더 전용 도구를 전체로 옮기기: 확인 후 복사합니다. 원본 삭제는 따로 한 번 더 확인합니다.
- 옛 캐시 지우기: 확인 후 지웁니다.
- 이 플러그인 자신은 끌 수 없게 막아 두었습니다.

## 알려진 한계

- **윈도우의 Claude Code 데스크톱 앱에서만 확인했습니다.** 맥, 리눅스, 터미널, VS Code에서는 확인하지 못했습니다. 코드에 맥·리눅스용 분기는 있지만 실행해 본 적이 없습니다.
- Claude Code 전용입니다. Claude Code 밖에서 쓴 도구는 자동으로 알 수 없어서, 필요하면 `/ai-log`로 직접 기록해야 합니다.
- **추천은 이 PC에 받아 둔 플러그인 디렉터리 파일(`plugin-directory-cache-v2.json`)에 의존합니다.** 파일이 없거나 이름이 바뀌면 추가한 마켓플레이스 목록으로만 찾습니다. GitHub 검색은 그와 상관없이 동작합니다.
- 추천은 단어 사전으로 주제를 알아봅니다. 사전에 없는 주제는 놓칠 수 있고(그럴 땐 `/ai-find 원하는 기능`), 별 개수가 많다고 좋은 도구는 아닙니다.
- **출처 등급과 주의 신호는 디렉터리 기록과 GitHub 응답에 든 값만으로 정한 것입니다.** 저장소의 코드를 직접 읽어 안전한지 검사하지는 않습니다. 소유자 이름이 맞아도 코드가 안전하다는 뜻은 아닙니다.
- GitHub 검색은 로그인 없이 쓰므로 1분에 10번까지입니다.
- 번역 품질은 모델에 따라 다릅니다. 어색한 번역을 발견하면 알려 주세요.

## 문제가 생겼을 때

| 증상 | 해 볼 것 |
| --- | --- |
| 패널이 안 보인다 | `/ai-tools`를 입력합니다. 그래도 안 되면 Claude Code를 완전히 껐다가 다시 켭니다. |
| 패널에 "Nothing to show yet"이라고만 나온다 | 패널을 그리다 오류가 났다는 뜻입니다. `/ai-tools`를 다시 입력해 보고, 계속되면 Issues에 대화창에 뜬 오류 줄(`ai-tool-tracker: … hook skipped`)을 붙여 주세요. |
| 설명이 영어로 보인다 | 번역이 끝나는 중일 수 있습니다. 몇 분 뒤에도 그대로면 환경 탭의 "번역 상태"를 확인하고 알려 주세요. |
| 추천이 안 나온다 | 사전에 없는 주제일 수 있습니다. `/ai-find 원하는 기능`으로 직접 찾아 보세요. |
| GitHub 검색이 "rate limit"으로 실패한다 | 로그인 없이 쓰는 검색은 1분에 10번까지입니다. 1분 뒤에 다시 시도하세요. |
| 켜기/끄기, 옮기기가 실패한다 | 환경 탭의 "감지한 환경"에서 `claude` 명령이 있는지 확인하세요. |
| 맥·리눅스에서 이상하다 | 아직 확인하지 못한 환경입니다. Issues에 환경 정보와 함께 알려 주세요. |

## 용어를 모르신다면

- **플러그인**: Claude Code에 기능을 덧붙이는 묶음입니다. 스킬, 에이전트, MCP 서버, 훅을 담을 수 있습니다.
- **스킬**: 특정 작업의 방법을 적어 둔 지침서입니다. 부르거나 Claude가 필요하다고 판단할 때만 읽어서 따릅니다. 안 쓰는 동안은 이름과 한 줄 설명만 올라가 있습니다.
- **MCP 서버**: 외부 서비스(Notion, Figma 등)와 연결해 주는 도구입니다.
- **훅**: 어떤 일이 일어날 때 자동으로 실행되는 코드입니다. 켜져 있는 동안 계속 동작하므로, 끄면 효과가 가장 큽니다.

## 오류 제보와 개선 제안

[Issues](https://github.com/newpy15/ai-tool-tracker/issues)에 남겨 주세요. 양식을 준비해 두었습니다.

- 오류: 패널 **환경** 탭의 "감지한 환경" 내용을 붙여 주시면 원인을 찾기 쉽습니다. (사용자 이름이 든 경로는 가려 주세요.)
- 제안: "이런 말을 했을 때 이런 도구가 추천되면 좋겠다"처럼 예시가 있으면 더 좋습니다.
